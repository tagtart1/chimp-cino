## Local Development

This repo uses pnpm workspaces for the frontend and backend apps.

1. Copy `.env.example` to `.env` and fill in the backend environment values.
2. Install dependencies from the repo root:

   ```sh
   pnpm install
   ```

3. Start both dev servers from the repo root:

   ```sh
   pnpm dev
   ```

The frontend runs on `http://localhost:3000` and the backend runs on `http://localhost:3001`.
